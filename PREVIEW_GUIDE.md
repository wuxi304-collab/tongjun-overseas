# Preview Guide

V4 fixes the unstyled HTML preview issue by inlining the production CSS/JS into each HTML page.

## Fastest
Open `index.html` directly. It should retain the full visual system even in restricted file preview environments.

## Recommended local preview on Windows
Double-click `start-preview.bat`, then open: http://127.0.0.1:8765/

## macOS / Linux
Run `./start-preview.sh` then open http://127.0.0.1:8765/
