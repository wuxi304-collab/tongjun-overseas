# RELEASE V16 — High-Performance Materials Editorial Refinement

Date: 2026-09-07

## Why this release exists

V15 established the controlled technical-document system. V16 tightens the public-facing corporate language and homepage hierarchy so the site reads like an engineering-led high-performance materials business rather than a generic export catalogue.

## Changes

- Reframed the hero around engineering-led sourcing, source-role clarity and evidence-backed commitment.
- Replaced defensive public language with positive qualification language.
- Added a Performance Envelope rail: temperature, corrosion, mechanical load, dimensional stability and approval constraints.
- Removed public-facing competitor/style references while retaining internal design-reference documentation.
- Refined utility-bar language and RFQ naming toward technical procurement use.
- Added late-stage V16 CSS for stronger full-bleed hero hierarchy and industrial data-rail behavior.
- Preserved all V15 technical tools, controlled documents, SEO routes, RFQ routing and qualification boundaries.

## Positioning rule

Tongjun Special Metals is presented as a sourcing and qualification desk. Manufacturing, stockholding and processing roles must remain explicitly separated in claims and RFQ responses.
