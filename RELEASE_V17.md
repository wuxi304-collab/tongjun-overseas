# RELEASE V17 — Challenge-to-Evidence Conversion System

Date: 2026-09-07

## Objective

V17 strengthens the procurement workflow around one path:

**difficult specification → qualified route → planned evidence package → trial / scale decision**

The release does not expand the catalogue for its own sake. It makes the existing technical system more useful to an engineering buyer before quotation.

## Homepage

- Hero language is more concrete about precision strip, nickel alloys, Invar tooling plate and heavy project plate.
- Added a four-stage operating protocol: Define → Qualify → Verify → Scale.
- Added a flagship controlled-reference rail for Alloy 625, Alloy 718, Alloy C-276 and Invar 36.
- Separated flagship technical references from engineering tools so the resource hierarchy is less repetitive.

## RFQ

- Added a four-part review-return contract: Route, Gaps, Evidence and Commercial Basis.
- Added a dynamic Evidence Package Preview generated from the RFQ fields.
- The structured RFQ body and API payload now carry evidence-package planning.

## Material / route pages

- Alloy 625 now exposes four qualification gates before price: product-form standard, dimensions/condition, source role/origin and evidence package.
- Supply Route now exposes a route-output contract: starting route, backup route, evidence first and open assumptions.

## Boundary

The evidence package preview is a planning checklist. It is not a certification promise, stock promise, origin promise or manufacturing-capability claim. Final supply remains subject to the governing purchase order, source confirmation and buyer approval where applicable.
