# RELEASE V17 — Challenge-to-Evidence Conversion System

Date: 2026-09-07

## Objective

Move the site from a strong technical catalogue into a stronger procurement workflow: difficult specification → qualified route → planned evidence package → trial / scale decision.

## Changes

- Homepage hero made more concrete around difficult specifications and explicit source roles.
- Added a four-stage operating protocol: Define → Qualify → Verify → Scale.
- Replaced a duplicate resources block with flagship controlled technical references for Alloy 625, Alloy 718, Alloy C-276 and Invar 36.
- RFQ now explains the expected technical-review output and builds an evidence-package planning checklist from the entered requirement.
- RFQ structured payload now carries `evidence_package` for downstream webhook routing.
- Alloy 625 sourcing page now exposes four independent qualification gates before quotation.
- Supply Route page now states a four-part output contract: starting route, backup route, evidence first and open assumptions.

## Boundary

The evidence package preview is a planning checklist, not a certification, stock, origin or manufacturing capability promise. Final acceptance remains governed by the PO, applicable standard, approved source controls and certified source documentation.
